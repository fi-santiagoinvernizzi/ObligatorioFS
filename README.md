Uso de IA:
La IA fue usada principalmente para la creacion de los casos de prueba en postman, dado que puede proporcionar los scripts para los tests para hacerlos de una forma mas rapida. Tambíen fue utilizada para ver como consumir las APIs externas, tanto la de Gemini como la de TMBD mediante Axios. A su vez, fue utilizada a lo largo de todo el proyecto para debuggear y solucionar errores causados ya sea por incompatibilidades entre versiones o por incoherencias de código. También fue utilizada a la hora de revisar código antiguo provisionado por el profesor en caso de dudas a la hora de extrapolarlo a el proyecto. La IA que fue utilizada fue ChatGPT en su versión gratuita.
